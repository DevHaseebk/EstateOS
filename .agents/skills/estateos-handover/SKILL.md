# EstateOS handover

Update docs/AI/CURRENT-STATE.md and docs/AI/HANDOVER-LATEST.md after meaningful work. Preserve unfinished work and prior findings; add a current section above history instead of discarding it.

Record the date, active milestone, approved scope, branch and commit or uncommitted status, completed work, exact changed paths, checks actually run with results, decision IDs followed, unresolved issues, next recommended task, and things the next agent must not change.
