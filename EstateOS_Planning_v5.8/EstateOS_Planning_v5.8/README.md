Owner/super-admin creates agency; basic company data; choose premium website template; fill logo/hero/sections/images; optional properties; private preview; Super Admin manually approves and can block/deactivate; public website link only after approval. Design modern, premium, easy for nontechnical agents on mobile and desktop. CRM is part of longer-term vision; exact pilot CRM scope remains open.
