## The independent D-048 decision (My Website landing screen only)

Choose **how My Website groups website status/readiness with the existing three subordinate tools**. D-048 does NOT approve editor save/publish behavior, theme-change persistence, detailed forms or route labels.

### Option A — Guided Website Hub (RECOMMENDED)

- A top compact website **readiness/status** area shows actual status and what essentials remain (if anything); never mislabels pending approval as live.
- One obvious primary CTA, generally `Edit Website`/`Complete Website` depending on actual readiness; only show `Open Live Website` for a real live URL (illustrative copy only).
- Immediately below, **three clear direct-access choices**, e.g. `Choose Theme`, `Edit Website`, `Preview Website`, visually distinguishable but not competing with primary CTA.
- Private preview while Pending; zero properties supported. Mobile stacks this into a simple single column.
- **Best for:** first-time property agents who need orientation and a minimal learning curve.

### Option B — Compact Tabs

- My Website has a compact summary header with tab navigation for Theme, Editor, Preview.
- Tabs expose these three subviews without a separate landing/action hub; status is visually smaller.
- **Trade-off:** users may miss website readiness details and confuse preview with live status.

### Option C — Editor-First Landing

- My Website opens directly into the section editor. Theme and Preview are obvious adjacent actions.
- Suitable for advanced editors but more demanding on first-time users; readiness context may be less noticeable.

## Invariants regardless of choice

- D-047 controls **Overview** and stays separate; D-048 controls **My Website** only.
