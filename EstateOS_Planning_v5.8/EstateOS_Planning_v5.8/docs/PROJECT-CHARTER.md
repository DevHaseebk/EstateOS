## Objective

Launch a tiny pilot for 2–3 small real estate agencies (1–10 agents each): their own premium modern branded website using a simple section-based builder, with optional property listings; platform Super Admin creates/sees/reviews agencies, manually approves, blocks or deactivates. Agency public link only after approval. Long-term hybrid vision includes simple CRM, but exact pilot inbox is OPEN.

## User experience

Simple English, equivalent mobile and desktop capability, visual guidance, very few steps, nontechnical agency owners. The website must make sense with zero properties.

## Delivery controls

Plan and obtain approvals before coding; milestones and acceptance criteria; one main repository; Claude Code/Cursor/Codex collaboration through Markdown decisions, changelog and handovers. Favor straightforward maintainable architecture. Owner available 5–10 hours/week.

## Exclusions from pilot

Mandatory verification documents, office map-pin proof, verified-email approval gate, document-retention system, full drag/drop builder, automation, payment system and advanced CRM. Historical D-018/D-021/D-023–D-027 remain on record but are deferred by D-028.
